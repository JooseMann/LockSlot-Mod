<h2>LockSlot: A Minecraft Mod for a Better Inventory</h2>

LockSlot is a simple Minecraft mod that allows the user to place a lock on an inventory slot, preventing that slot from having its item dropped on accident.


<h4>Future Features</h4>

1. Implement the locking mechanic
2. Create a GUI-based way to show the player that a specific slot is locked
